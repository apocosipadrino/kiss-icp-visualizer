KISS-ICP is a LiDAR odometry method: it estimates how the sensor moved by aligning each new scan to a map built from previous scans, using point-to-point ICP. It keeps the pipeline deliberately simple — no features, no IMU, no loop closure — just adaptive voxel downsampling, a robust kernel, and a constant-velocity motion model, and still outperforms far more complex systems on public benchmarks. This 2D demo runs three odometry methods on the same robot, the same map, and the same scans, so only the method differs.
